Course:web technology (frontend)|Assignment #1. HTML & CSS Basics
## assignment objectives
•	Understand the structure and purpose of HTML.
•	Use basic and intermediate HTML tags to create a simple webpage.
•	Apply knowledge of text formatting, images, links, lists, tables, and forms.
•	Understand the role of CSS in web development.
•	Apply CSS properties to style colors, fonts, and page backgrounds.
•	Create structured webpage layouts using CSS (colors, fonts, margins, padding, borders).
•	Publish their first webpage online.
